# Suraj Bhan Pratap Singh — Portfolio

## Overview
Personal engineering portfolio of **Suraj Bhan Pratap Singh** — Full Stack Developer & AI Engineer. Showcasing production-oriented full-stack web applications, authenticated AI workflows, verified internship experience, formal credentials, and curriculum vitae.

## Tech Stack
- **Frontend**: React 19, TypeScript, Tailwind CSS 4, Vite 8
- **Icons & UI**: Lucide React, Custom SVG Icons
- **Deployment**: Vercel

## Sections
- **Hero**: Developer introduction, positioning statement, and status.
- **About**: Engineering philosophy, core focus areas, and technical background.
- **Featured Case Studies**: Deep technical showcases for Tier A production projects.
- **AI Systems & Architectures**: LLM inference workflows, generative study aids, and agentic AI.
- **Additional Projects**: Curated secondary repositories and utilities.
- **Capabilities Matrix**: Categorized breakdown of programming languages, frameworks, AI tooling, databases, and security.
- **Work Experience**: Verified timeline covering internships at Edunet Foundation (AI & Emerging Technologies) and ApexPlanet Software.
- **Certifications & Education**: Formal credentials (Naukri Campus, Simplilearn, Cisco, Edunet) and B.Tech CSE coursework.
- **Resume Hub**: Interactive ATS-formatted resume viewer and direct PDF document download.
- **Contact & Footer**: Direct email copy, mailto trigger, and professional profiles.

## Featured Projects
- **StudySnap**: AI-powered study platform and intelligent revision companion with Groq LLaMA-3.1 inference, Neon PostgreSQL, Drizzle ORM, Clerk auth, and installable PWA support.
- **Cartify**: Full-stack e-commerce platform with Razorpay payment processing, server-authoritative checkout, rate-limiting, and Google OAuth.

## Additional Project
- **Notes Nexus Labs (AI Study Buddy)**: Generative AI summarization and flashcard generator powered by the Google Gemini API.

## Features
- Dark editorial design system with high-contrast typography
- 100% responsive across mobile, tablet, and widescreen desktop
- In-depth architectural case study modals
- In-app PDF certificate viewer with official verification records
- Dual-mode resume hub (clean formatted view + PDF viewer)
- Complete accessibility (keyboard navigation, ARIA dialogs, focus trapping, ESC handlers)
- Production SEO with Open Graph and Twitter/X metadata

## Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

## Build

To create a production bundle:
```bash
npm run build
```
